# Dev Pipeline -- Fix PDF viewer height and scrollability in review detail pane
**Issue:** #115
**PR:** (filled in Phase 3)
**Started:** 2026-03-28
**Branch:** 115-fix-pdf-viewer-height

## Phase 1: Problem Statement

**Root cause:** The `ReviewDetail` component renders `grid h-full grid-cols-1 xl:grid-cols-[1fr_360px]`. The `h-full` makes the entire grid equal to the height of the outer `main.overflow-y-auto` container. At the `xl` breakpoint (two columns, side-by-side), this is fine - both columns are viewport height, and the right column scrolls independently. But at single-column layout (< xl), the PDF section stretches to `h-full` with no independent max-height, and since it's a flex child with `flex-1`, it eats the full available height. The form fields section below it is pushed out of the visible area.

**Affected files:**
- `apps/web/src/pages/ReviewerDashboard.tsx` lines 743-745 (the ReviewDetail grid and left section)

**Layout hierarchy:**
- Root: `div.flex.h-screen.flex-col.overflow-hidden` (full screen)
- Two-pane: `div.flex.flex-1.overflow-hidden`
  - Detail pane: `main.flex.flex-1.flex-col.overflow-y-auto` (the scrollable container)
    - ReviewDetail: `div.grid.h-full.grid-cols-1.xl:grid-cols-[1fr_360px]` (height-locked to viewport)
      - Left section (PDF): no max-height bound
      - Right section (fields): `overflow-y-auto` but height same as left

## Phase 2: Solution Space

**Options considered:**
1. **Remove `h-full` entirely** - grid sizes to content in all modes. Breaks the side-by-side bounded layout at xl.
2. **Move `h-full` to `xl:h-full`** + add `max-h-[60vh]` on the left section for single-column. Clean, minimal change.
3. **Restructure layout** to use CSS subgrid or explicit row heights. Over-engineered.

**Chosen:** Option 2 - move `h-full` to `xl:h-full` (two-column only), and add `max-h-[60vh] xl:max-h-none` on the PDF section. This:
- At xl (two-column): grid is h-full, both columns fill viewport height, right column scrolls independently. Same behavior as before.
- At < xl (single-column): grid sizes to content, PDF is capped at 60vh, fields flow naturally below. Outer `main.overflow-y-auto` scrolls if total content exceeds viewport.

## Phase 3: Execute

**Change:** 2-line diff in `apps/web/src/pages/ReviewerDashboard.tsx`

```diff
-    <div className="grid h-full grid-cols-1 xl:grid-cols-[1fr_360px]">
+    <div className="grid grid-cols-1 xl:grid-cols-[1fr_360px] xl:h-full">
       {/* Document viewer */}
-      <section className="flex flex-col border-r border-slate-200" aria-label="Source document">
+      <section className="flex flex-col border-r border-slate-200 max-h-[60vh] xl:max-h-none" aria-label="Source document">
```

**Build result:** Clean. `pnpm check` passes (frontend + backend builds succeed).
